JavaScript 对象

用一个学生对象认识属性、方法与引用

对象 = 属性 + 方法

属性描述对象的特征，方法描述对象可以执行的动作。学生对象可以保存基本资料、兴趣，也可以定义学习和睡觉的方法。

对象创建与常见操作

var student = {
    name: "张三",
    age: 18,
    sex: "男",
    class: "高三一班",
    hobby: ["看电影", "足球", "看书"],
    study: function() {
        console.log("学习");
    },
    sleep: function() {
        console.log("睡觉");
    }
};

console.log(student.name);      // 读取属性
student.study();                // 调用方法
delete student.sleep;           // 删除属性或方法
console.log("sleep" in student); // 判断属性是否存在

for (var key in student) {      // 遍历对象
    console.log(key, student[key]);
}

var o = student;                // 复制引用，不是复制对象
o.name = "王五";
console.log(student.name);      // 王五：两者指向同一个对象

属性与方法

可用点语法读取属性并调用方法；使用 delete 删除成员，再用 in 检查是否存在。

引用赋值

var o = student 只复制对象的引用。修改 o.name 后，student.name 也会变成“王五”。

对象属性与方法

var studentCard = {
    name: "张三",
    age: 18,
    sex: "男",
    hobby: ["篮球", "足球", "羽毛球"],
    grade: "大三",
    introduce: function() {
        return `我的名字叫：${this.name}，年龄：${this.age}，性别：${this.sex}，年级：${this.grade}，爱好：${this.hobby}`;
    },
    upgrade: function() {
        const grades = ["大一", "大二", "大三", "大四"];
        const index = grades.indexOf(this.grade);
        this.grade = index !== -1 && index < grades.length - 1
            ? grades[index + 1]
            : "毕业";
        return this.grade;
    }
};
