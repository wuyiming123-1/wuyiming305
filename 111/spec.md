> 版本：v1.0　日期：2026-10-21

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 项目名称 | 网页抓小球小游戏 |
| 目标文件 | `wymck/111/ball-game.html`（新建，单文件） |
| 技术栈 | 原生 HTML + CSS3 + JavaScript（ES6+），**不使用任何框架、库、外部图片或音频文件** |
| 运行环境 | Chrome / Edge 最新版，双击本地打开即可运行 |
| 玩法一句话 | 2 分钟倒计时内，点击不断随机出现的小球得分，点空白扣分，拼出最高分 |

## 2. 核心常量（可配置，集中定义在 JS 顶部）

| 常量 | 值 | 说明 |
|---|---|---|
| `GAME_DURATION` | 120 | 游戏时长（秒），即 2 分钟倒计时 |
| `BALL_LIFETIME` | 3000 | 小球存活时限（ms），超时自动消失换位 |
| `BALL_SIZE_MIN / MAX` | 36 / 60 | 小球直径随机范围（px） |
| `SCORE_HIT` | +2 | 点中小球得分 |
| `SCORE_MISS` | -1 | 点击空白区域扣分 |
| `COMBO_THRESHOLD` | 3 | 连击数 ≥3 时，每次点中额外 +1（即 +3） |
| `WARN_TIME` | 10 | 倒计时最后 10 秒时间数字变红 |

## 3. 页面布局与视觉

### 3.1 背景
- 纯色浅黄背景，`#FFF9C4`（最终色值允许 ±微调，但必须是"纯色浅黄"风格）。
- `overflow: hidden`，禁止出现滚动条。

### 3.2 顶部信息栏（常驻）
一条横向信息栏（深色 `#222` 圆角卡片、白字），从左到右展示 4 项：

| 项 | 说明 |
|---|---|
| 分数 | 实时分数，变化时数字轻微放大回弹（~150ms）；负分显示为红色 |
| 剩余时间 | `mm:ss` 格式倒计时；最后 10 秒变红并轻微脉冲 |
| 连击 | 显示 `xN`；连击 ≥3 时高亮为橙色 |
| 最高分 | 从 localStorage 读取的历史最高分 |

### 3.3 开始按钮
- 待开始状态下，页面正中显示大号圆角按钮 **「开始游戏」**，带 hover 放大效果。
- 点击后按钮隐藏，游戏立即开始。
- 游戏进行中顶栏与信息栏的点击**不产生任何游戏效果**（见 6.4 边界规则）。

### 3.4 小球
- 蓝色圆形小球（`radial-gradient` 呈现轻微立体感），直径随机 36~60px。
- 位置随机，约束条件：
  - 完整位于可视区域内（坐标范围 `0 ~ innerWidth/Height - 球径`）；
  - 不允许出现在顶部信息栏下方高度以内（可活动区域 = 信息栏底边 → 页面底部）。
- 任意时刻页面上**只有 1 个小球**。

## 4. 游戏流程（状态机）

```
[待开始] --点击「开始游戏」--> [进行中] --120s 倒计时结束--> [结束]
                                   ^                          |
                                   |______点击「再来一局」______|
```

1. **待开始**：顶栏显示 分数 0 / 时间 2:00 / 连击 x0 / 历史最高分；居中「开始游戏」按钮；无小球。
2. **进行中**：启动倒计时，生成第 1 个小球；此后按第 5 节规则循环。
3. **结束**：时间到 → 停止计时、清除小球与所有定时器 → 弹出居中结束面板。
4. **再来一局**：面板隐藏，分数归 0、连击归 0、时间重置为 2:00，直接进入「进行中」（无需再点开始按钮）。

### 4.1 结束面板内容
- 标题「时间到！」
- 最终得分（大号数字）
- 命中率 = `点中次数 ÷ (点中次数 + 点空白次数)`，百分比显示，无点击时显示 `--`
- 历史最高分；若本局破纪录，显示高亮徽标「新纪录！」
- 按钮「再来一局」

## 5. 小球与计分规则

### 5.1 小球生命周期
| 阶段 | 行为 |
|---|---|
| 出现 | 随机位置 + 随机大小，`scale 0→1` 弹出动画（~200ms） |
| 存活中 | 静止不动等待点击；最后 1 秒闪烁/脉冲提示即将消失 |
| 被点中 | 缩放淡出动画（scale 1→1.4 + 透明，~200ms）后移除，立即生成新球 |
| 超时消失 | 直接淡出移除，立即生成新球，**重置连击**（不扣分） |

### 5.2 计分规则
| 操作 | 分数 | 附加效果 |
|---|---|---|
| 点中小球 | **+2** | 连击 +1；若连击 ≥3，本次改为 **+3** |
| 点击游戏区域空白处 | **-1** | 连击归零 |
| 小球超时消失 | 0 | 连击归零 |
| 点击顶栏/按钮/面板 | 0 | 无任何效果 |

- 分数**可以为负**，无下限。
- 连击定义：连续点中小球的次数；点空白或小球超时都会打断。
- 飘字反馈：在点击位置冒出 `+2` / `+3`（橙色）/ `-1`（红色），上浮约 40px 并淡出（~700ms）。

### 5.3 音效（Web Audio API 合成，无音频文件）
| 事件 | 音效 |
|---|---|
| 点中小球 | 短促"叮"（正弦波 ~880Hz），连击越高音调越高 |
| 点空白扣分 | 低频短音（~200Hz） |
| 倒计时结束 | 下行三连音 |

- `AudioContext` 在首次用户点击（开始游戏）时创建，规避浏览器自动播放限制。
- 提供右上角静音开关（小图标按钮，纯 CSS 绘制），状态存入 localStorage。

## 6. 数据与边界规则

### 6.1 持久化（localStorage，key 前缀 `ballGame.`）
| key | 内容 |
|---|---|
| `ballGame.bestScore` | 历史最高分 |
| `ballGame.muted` | 静音状态 |

### 6.2 防御细节
- `user-select: none` 防止快速点击选中页面文字。
- 所有 `setInterval` / `setTimeout` 在游戏结束时统一清除，防止"再来一局"后出现重复计时。
- 窗口 resize 不做即时处理；新球生成时始终基于当前 `innerWidth/innerHeight` 计算，自然纠正。

### 6.3 性能
- 小球与飘字用绝对定位 DOM + CSS transition/animation 实现，不引入 Canvas。
- 动画结束后及时 `remove()` 节点，避免 DOM 无限增长。

### 6.4 事件判定细则
- 小球点击：`stopPropagation()`，防止同时触发空白扣分（同原型逻辑）。
- 空白扣分仅对游戏区域内的点击生效：通过 `e.target` 判断，点击顶栏、开始按钮、结束面板及其内部元素一律忽略。

## 7. 验收清单（Acceptance Checklist）

- [ ] 双击打开页面：浅黄背景、顶栏 4 项信息、居中「开始游戏」按钮，无小球
- [ ] 点击开始：按钮消失，倒计时从 2:00 开始递减，小球弹出
- [ ] 小球大小、位置每次随机，且始终完整可见、不遮挡顶栏
- [ ] 点中小球：+2 飘字、分数更新、旧球缩放淡出、新球立即出现
- [ ] 连续点中 3 次后：每次 +3，顶栏连击数橙色高亮
- [ ] 点空白：-1 红色飘字、连击归零、负分正常显示为红色
- [ ] 小球 3 秒未点：最后 1 秒闪烁，超时淡出换位，连击归零但不扣分
- [ ] 最后 10 秒：时间数字变红脉冲；时间到：音效 + 小球清除 + 结束面板弹出
- [ ] 结束面板：得分、命中率、最高分正确；破纪录时显示「新纪录！」
- [ ] 「再来一局」：数据全部重置并直接开新局，无重复计时（玩 2 局以上验证）
- [ ] 刷新页面：历史最高分仍在；静音开关状态被记住
- [ ] 全程无滚动条、无双击选字问题，动画流畅无明显卡顿
