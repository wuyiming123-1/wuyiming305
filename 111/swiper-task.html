AI 任务一 · 提示词工程师不写代码 · 让 AI 听懂需求 · 两轮迭代留痕（提示词访问入口就在本区）

把需求翻译成提示词，让 AI 生成 new Swiper('#mySw4', {...}) 配置：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果为 cube。以下保留每轮提示词与 AI 回答，并亲自粘贴到页面逐项验证。

第 1 轮：第一版提示词（有遗漏，AI 答案不合格）

我的提示词 
用 Swiper 11 写一个轮播配置：可以无限循环，每 3.2 秒自动翻页，用户手动拖动后自动播放不要停，底部有可以点击跳转的圆点分页器，初始效果用 3D 立方体 cube。
AI 回答（第 1 轮） 
new Swiper('#mySw4', {
  loop: true,
  autoplay: { delay: 3200, disableOnInteraction: true },    // ← 错：true 表示手动操作后"停止"
  pagination: { el: '.swiper-pagination', clickable: true }, // ← 错：页面容器是 #wyPag4，默认类名找不到
  effect: 'cube',
});

验证结论：粘贴后圆点不显示（el 没对上页面结构），手动拖一下自动播放就停了——需求③④不满足，第 1 轮不合格。

第 2 轮：把错处说清楚后再问（验证通过）

修正版提示词 
你上面有两处错：① disableOnInteraction 要设为 false 才表示"手动操作后自动播放继续"，true 会停止；② 我的分页器容器是页面里已存在的 <div id="wyPag4">，el 必须指向 #wyPag4。请按这两点重新给出完整配置，初始效果保持 cube。
AI 回答（第 2 轮） 
new Swiper('#mySw4', {
  loop: true,                                             // ① 无缝循环
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false }, // ② 3.2 秒且手动后不停
  pagination: { el: '#wyPag4', clickable: true },         // ③ 圆点可点击跳转
  effect: 'cube',                                         // ④ 初始 3D 立方体
});
  • 无缝循环：翻到最后一张继续往后翻，回到了第一张
  • 3.2 秒自动翻页：掐表约 3 秒一翻，节奏正确
  • 手动操作后不停止：拖动松手后它接着自动翻
  • 圆点可点：点第 3 个圆点直接跳到第 3 张
  • 初始 cube：刷新页面即是 3D 立方体效果

答辩抽问备答：第一版漏掉/写错的是 disableOnInteraction 的取值语义（AI 默认给了 true，与需求正好相反）和 pagination.el 没对上页面结构。第二轮我把"true=停止、false=不停"的语义、"el 要指向我页面里已有的 id"这两点明确写进提示词，AI 才给对。第一版代码错在：参数语义记反 + 选择器想当然。

AI 任务二 · creative 仿写课堂只讲了 6 种 effect · 第 7 种 creative 由 AI + 官方 demo 257 自学

参考官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法，为演示四新增第 7 个按钮 [creative 电影胶片]（见上方演示四）。效果要求：上一张缩小左移并带角度，下一张放大右移并带角度——像电影选片墙（参数自定）。

核心配置（点"creative 电影胶片"按钮即生效）

creativeEffect: {
  prev: { translate: ['-118%', '-6%', -260], rotate: [0, 0, -14], opacity: .55, shadow: true },
  next: { translate: ['106%',  '8%', -120], rotate: [0, 0,  10], scale: 1.15, opacity: .8, shadow: true },
}

用自己的话解释 prev / next 的 transform 各控制什么：
prev 描述"上一张"该停在哪儿：向左移出约 1.18 倍自身宽度、略微上移、沿 z 轴后退 260px 显得更远，再绕 z 轴逆时针歪 14 度、透明度降到 0.55——像贴在墙上的一张旧海报；next 描述"下一张"从哪儿来：向右移出约 1.06 倍宽度、微上移、后退 120px、顺时针歪 10 度、放大到 1.15 倍并压暗一点——像选片墙上被推到你面前的下一张海报。切换动画时 Swiper 在这两个姿态之间做连续插值，就有了"胶片翻找"的观感。

答辩抽问备答：① transform 里的百分号是相对 slide 自身的宽/高（-118% 就是向左移动 1.18 倍自身宽度），第三个数值是沿 z 轴的像素偏移；② 想让卡片转 20 度，把 rotate 数组第三个分量改成 20 或 -20 即可，例如 rotate: [0, 0, 20]——next 卡片就会顺时针翘起 20 度。我试过：角度太大会显得乱，10 度左右最像选片墙。

② 课堂没讲过的能力：keyboard 键盘控制（keyboard / mousewheel / zoom / parallax 四选一）

我的提示词 
Swiper 11 里想让轮播支持键盘左右方向键翻页，但页面本身很长，不能让方向键劫持页面滚动。该怎么配置？参数分别是什么意思？
AI 关键回答 
keyboard: {
  enabled: true,        // 开启键盘控制：ArrowLeft / ArrowRight 翻页
  onlyInViewport: true, // 只有轮播在可视区内才监听方向键，不干扰页面滚动
}

键盘控制已同时写入演示四的初始配置和切换效果重建的配置（按钮切效果是销毁重建，不重配键盘会失效）。验证：把轮播滚进视野按 ←/→ 能翻页；滚到页面其它位置再按方向键，页面正常滚动、轮播不动。

答辩四连问备答

1. 这段代码什么意思？——keyboard 模块在初始化时注册 keydown 监听，方向键按下时调用 slidePrev() / slideNext()，等效于点左右箭头。
2. AI 第一次给的哪里不对、你怎么改？——AI 第一次只给了老版本的简写 keyboard: true，没有 onlyInViewport，页面一打开按方向键轮播就抢着翻、页面滚不动；我追加 onlyInViewport: true 后，只有轮播出现在视野内才接管方向键。
3. 新参数的作用？——onlyInViewport 限定"轮播在可视区"才响应键盘，是键盘控制与页面滚动和平共处的关键；enabled 是模块总开关。
4. 顺便把 autoplay 的 delay 从 3200 改成 6000 有什么变化？——自动翻页间隔从约 3.2 秒变 6 秒，每张停留更久、节奏更从容，适合展馆大屏；太快看不清、太慢显得"死"，3200 是比较舒服的节奏。
