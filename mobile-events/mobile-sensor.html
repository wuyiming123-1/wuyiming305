为什么必须做降级？

devicemotion 依赖硬件加速度计：普通电脑没有传感器，事件永远不来； 有的设备会触发事件但 accelerationIncludingGravity 为 null； iOS 13+ 出于隐私要求必须由用户点击授权；用户还可能拒绝授权。 这四种情况下如果只写"监听 + 判阈值"，页面就是一片死寂甚至控制台报错。 所以完整链路是：检测 API 是否存在 → iOS 弹授权 → 收不到有效数据就切降级方案， 任何情况下用户都能玩到功能，控制台无报错。

accelerationIncludingGravity 与 acceleration 的区别

  • accelerationIncludingGravity：设备测到的原始加速度，含重力分量。手机静止平放时它 ≈ (0, 0, 9.8)——那 9.8 就是重力。合成加速度静止时约 9.8，摇动时远超 18，所以阈值判摇动用它最直观。
  • acceleration：去掉重力后的线性加速度（设备相对自由落体参考系的加速度）。静止时 ≈ 0，更"纯净"，但靠它判摇动需要算变化率，实现更绕；而且部分安卓设备只提供含重力的原始值。
